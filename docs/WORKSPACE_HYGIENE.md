# Local Workspace Hygiene

This repository deliberately separates tracked research software and compact
scientific evidence from large local datasets, generated analyses, caches, and
Python environments.

A large checkout is not necessarily a large Git repository. Local NASA source
archives, imported row-level tables, analysis outputs, test scratch space, and a
virtual environment can occupy several gigabytes while remaining intentionally
untracked.

## Workspace Layers

| Layer | Typical paths | Git policy | Cleanup policy |
|---|---|---|---|
| Source and contracts | `src/`, `scripts/`, `configs/examples/`, `tests/` | tracked | modify only through reviewed changes |
| Compact scientific evidence | selected files in `data/processed/` and `data/platform/` | tracked | preserve negative, diagnostic, and inconclusive results |
| Raw source data | `data/raw/` | ignored | keep locally or in an approved external archive |
| Large regenerated imports | `data/processed/nasa_pcoe_battery_import/` and other documented row-level outputs | ignored | preserve while needed for reproducibility; archive before removal |
| Generated analyses | `outputs/` | ignored | classify before cleanup |
| Python environments | `.venv/`, `.venv313/`, other `.venv*` directories | ignored | delete only when no longer the validated active environment |
| Test and tool caches | `.pytest_tmp/`, `.pytest_cache/`, `__pycache__/`, `.mypy_cache/`, `.ruff_cache/` | ignored | safe to regenerate |

## Safe Immediate Cleanup

The following paths are caches or one-time local helpers and may be removed when
no process is using them:

```powershell
Remove-Item ".\.pytest_tmp" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item ".\.pytest_cache" -Recurse -Force -ErrorAction SilentlyContinue
Get-ChildItem . -Directory -Recurse -Force -Filter "__pycache__" |
    Remove-Item -Recurse -Force -ErrorAction SilentlyContinue
```

Deleting these paths does not remove source measurements or scientific results.
They will be regenerated by later test or Python runs.

## Review Before Deletion

Do not delete these areas merely because they are ignored:

- `data/raw/`;
- `data/processed/nasa_pcoe_battery_import/`;
- `outputs/nasa_pcoe_signal_enriched_battery_intelligence/`;
- completed audit ZIP files and their recorded SHA-256 values;
- the active `.venv313/` environment;
- any output that cannot be reproduced from a documented source, exact commit,
  configuration, and command.

Ignored means "local and not committed," not "disposable."

## Output Classification

Before deleting a generated output, assign exactly one class.

### Canonical evidence

A completed, checksum-recorded artifact required to support a scientific or
software closeout. Preserve it locally and in at least one external backup.

For the NASA PCoE case, the final post-remediation closed audit ZIP is canonical
evidence. Record its filename, SHA-256, producing commit, and scientific
conclusion beside the backup.

### Reproducible working output

A detailed local run that can be rebuilt from preserved raw/import inputs, an
exact software commit, configuration, and command. It may be removed after its
compact closeout and regeneration instructions are verified.

### Temporary output

A smoke-test run, cache, staging directory, failed partial package, or repository
inventory generated only for inspection. It may be removed after confirming it
is not referenced by a current audit or report.

## NASA PCoE Preservation Boundary

The following artifacts serve different roles and should not be conflated:

- official source archive and retrieval receipt: acquisition evidence;
- `data/processed/nasa_pcoe_battery_import/`: regenerated canonical import and
  import provenance;
- `outputs/nasa_pcoe_signal_enriched_battery_intelligence/`: detailed analysis
  and review artifacts;
- final closed audit ZIP: portable closeout package;
- compact tracked documentation: durable repository narrative and policy.

The predictive Ridge result remains `Unsupported`. Cleanup must not remove or
rewrite evidence simply because the result is negative.

## Prohibited Broad Cleanup

Do not run either command casually:

```powershell
git clean -fd
git clean -fdx
```

`git clean -fdx` can remove ignored raw data, imported NASA artifacts, completed
audit evidence, and virtual environments. Always inspect specific paths and use
explicit `Remove-Item -LiteralPath` commands instead.

## Pre-cleanup Checklist

1. Run `git status --short`.
2. Identify the source, purpose, size, and regeneration command for the target.
3. Confirm whether it is canonical evidence, reproducible working output, or
   temporary output.
4. For canonical evidence, verify its SHA-256 and external backup.
5. Delete only the reviewed explicit path.
6. Run `git status --short` again.
7. Run relevant tests only when source or tracked contracts changed.
