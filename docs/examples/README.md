# Research contract examples

The epistemic-transition examples are templates only. Replace every placeholder with exact, checksum-bound files before use.

- `epistemic_transition_proposal.example.json`: completed-result to successor-graph proposal. The proposed inference has no verified scientific authority by itself.
- `epistemic_verification_decision.example.json`: separate domain-verification decision that binds the exact proposal and parent graph before an inference edge may become `domain_verified`.

Simulation or computational-analysis examples must not be repurposed as empirical-validation evidence. External physical results enter only through the external-result-ingest boundary.
