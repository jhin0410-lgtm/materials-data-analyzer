# v2.2.0 - Materials Physics Features and Crystal Structure Evidence

## Overview

v2.2.0 adds a bounded Materials Project physics-evidence cycle on top of the
v2.1 scientific registry and trust layer. The release covers composition-derived
descriptors, JSON-safe scientific entity and quantity contracts, controlled
existing-ID structure enrichment, crystal-structure descriptors, deterministic
periodic graph artifacts, known-structure validation, prediction-interval
diagnostics, and scientific evidence closeout.

The release deliberately preserves negative and limited results. It does not
select a representative model and does not claim robust materials discovery,
DFT replacement, a validated GNN, a physics-constrained model, synthesizability,
phase-stability guarantees, calibrated uncertainty, or production scientific
decision support.

## Materials Project Dataset Scope

The v2.2 work uses the existing v1.3 Materials Project cohort:

- 838 rows
- Fe/Si-containing multinary compositions
- not a binary Fe-Si-only dataset
- target: original v1.3 `energy_above_hull`
- target unit: `eV/atom`

Current Materials Project API values are audit-only metadata. The original
target is not overwritten.

## Composition-Derived Physics Features

v2.2.1 adds bounded composition descriptors with documented property provenance,
including atomic-radius summaries, electronegativity summaries, configurational
mixing entropy, valence-electron concentration, and number of elements.

These features are composition-only and pre-structure. They do not use relaxed
crystal structures, phase labels, synthesis outcomes, or current API target
values.

## Negative Composition-Feature Result

The matched predictive comparison preserved the existing v1.3 split/model
policy. The actual decision is:

- decision: `performance_degraded`
- representative model selected: `false`

This means the generated composition-derived descriptors were used and tested,
but they did not improve the primary validation evidence.

## Structured Uncertainty and Unit Handling

The release distinguishes:

- source uncertainty
- numerical tolerance
- split variation
- prediction-interval diagnostics
- model-form limitations

Materials Project source uncertainty is recorded as unavailable rather than as
zero uncertainty. Prediction intervals are residual diagnostics in `eV/atom`;
they are not DFT uncertainty, source uncertainty, calibrated probability, or
out-of-domain guarantee.

## Controlled Structure Acquisition

v2.2.4 performs bounded existing-ID enrichment only:

- requested material IDs: 838
- returned material IDs: 838
- target drift: 0
- valid structure entities: 838
- descriptor rows: 838
- periodic graph artifacts: 838

The acquisition mode is limited to existing IDs. Broad queries, new material-ID
universe expansion, API-key persistence, and target overwrite are prohibited.
Structure chunks, entity records, graph bodies, and row-level structure outputs
remain local-only.

## CrystalStructureEntity and Operator Registry

Retrieved structures are converted into JSON-safe `CrystalStructureEntity`
records with lattice, periodic axes, sites, species, occupancy, fractional
coordinates, composition, source checksum, adapter version, schema version, and
provenance metadata.

The scientific operator registry records selected deterministic operators for
structure conversion, integrity validation, composition consistency, descriptor
summary generation, graph construction, and snapshot-alignment checks. These
operators are registered metadata and bounded functions, not arbitrary callable
execution.

## Structure Descriptors

Tier-1 known-structure descriptors include volume per atom, density,
ordered-structure flag, source-provided crystal-system/space-group categories,
nearest-neighbor distance summaries, coordination summaries, and descriptive
site-count metadata.

Raw lattice matrices, fractional-coordinate flattening, material IDs, row
indices, database timestamps, and target aliases are not primary predictive
features.

## Periodic Crystal Graph Artifacts

v2.2.4 generates deterministic periodic radius-graph artifacts for the 838
structures. The graph artifacts record node/edge metadata, distances, periodic
image vectors, builder version, and checksums.

These artifacts are representation artifacts only. They were not loaded as model
inputs, converted to graph tensors, embedded, or used to train a graph neural
network.

## Known-Structure Predictive Comparison

v2.2.5 evaluates a known-structure post-relaxation context using the
snapshot-aligned cohort and original v1.3 target. It compares fixed feature
sets under random, reduced-formula group, and chemical-system group validation:

- composition baseline
- composition physics
- structure-only
- baseline plus structure
- combined descriptors

The comparison does not change the composition-only pre-structure screening
result.

## Limited Structure-Predictive Result

The actual known-structure decision is:

- decision: `structure_predictive_value_limited`
- representative model selected: `false`
- graph model used: `false`

Structure descriptors improved only one primary group split. That is not enough
to claim a representative structure-aware model or robust predictive value.

## Prediction Interval Diagnostics

v2.2.5 adds split-conformal residual interval diagnostics for the
known-structure comparison. The tracked compact summary reports residual
diagnostic coverage and interval width for the evaluated context only.

These diagnostics do not provide DFT uncertainty, source uncertainty,
calibrated probability, phase-stability confidence, or production-grade
uncertainty.

## Reproducibility and Lineage

The tracked lineage preserves:

```text
v1.3 target dataset
-> composition entities/features
-> v2.2.1 predictive comparison

v1.3 material IDs
-> v2.2.4 current MP structures
-> CrystalStructureEntity records
-> structure descriptors
-> periodic graph artifacts

original targets + snapshot-aligned structure descriptors
-> v2.2.5 known-structure comparison
-> uncertainty diagnostics
-> v2.2.6 trust closeout
```

Closeout commands read tracked compact artifacts only. They do not call the API,
generate descriptors, load graph bodies, rerun models, or read row-level local
prediction outputs.

## Security and Local-Only Artifact Policy

Tracked artifacts are limited to source code, tests, docs, schemas, sanitized
configs, and compact aggregate summaries.

Local-only artifacts include:

- API chunks

- graph bodies
- periodic graph JSONL files
- predictions
- split assignments
- trained models
- local registry SQLite databases
- credentials and private configs
- generated reports under `outputs/`

No raw/local artifacts are attached to the release.

## Known Limitations

- No representative Materials model is selected.
- Composition-derived descriptors degraded the primary validation evidence.
- Known-structure descriptors provide limited evidence only.
- Relaxed structures are not available in a pre-structure screening context.
- The graph artifacts are not GNN evidence.
- Materials Project source uncertainty is unavailable.
- Prediction intervals are residual diagnostics only.
- No external validation or prospective materials-discovery validation is
  provided.

## What v2.2 Does Not Claim

v2.2.0 does not claim:

- robust stability prediction
- new material discovery
- DFT replacement
- synthesizability
- phase-stability guarantee
- calibrated scientific probability
- GNN or graph-model validation
- physics-constrained or hybrid physics-ML success
- production scientific decision support

## v2.3 Direction

Recommended v2.3 scope is a PGIR architecture RFC and representation-governance
design:

- map current scientific entities to future PGIR concepts
- define state, observation, field, parameter, control, relation, evaluator,
  transformer, propagator, uncertainty, and provenance boundaries
- establish schema ownership and migration governance
- avoid PDE solvers, PINNs, GNNs, and new predictive claims until the
  representation governance layer is explicit
