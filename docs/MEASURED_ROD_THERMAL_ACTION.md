# Measured-boundary rod action

The existing `mda-research-program run-autonomous` can execute one local typed action with `--rod-request REQUEST.json --rod-request-sha256 PIN --output EMPTY_OR_EXISTING_ROD_RUN --max-cycles 1`. Use `--repository-root` to identify the checkout containing the registered action. The request pin is supplied independently by the operator. The optional `--rod-prior-ledger` path must match `prior_ledger_sha256` in the request. The prior run remains read-only. CLI invocations without rod options use the existing audited IN625 mission.

## Contract v1.0

- Action `measured_boundary_rod_heat_transfer`, model `cylindrical_rod_fourier_dirichlet_neumann`, solver version and exact SciPy version. Constant k and volumetric heat capacity, cylindrical geometry, measured Dirichlet input at x=0, adiabatic far tip. A uniform initial temperature uses the first boundary sample. The two PDEs are axial diffusion and axial diffusion with a sink −4h(T−T_ambient)/(ρcD). Units and safe bounds are enforced by the request validator.
- `material` binds identity, source, density, specific heat, conductivity bounds and effective heat-sink bound. `geometry` binds SI length/diameter and ordered downstream sensor IDs/positions. External sensor placement and geometry provenance remain within the operator's responsibility.
- `temperatures` declares `excess_K` with a reference in K, `absolute_K`, or `absolute_degC`. Absolute encodings require a null reference. The model subtracts the separately specified physical ambient. Numerical checks use the declared grid, grid/BDF tolerances and time window.
- `partition` is one calibration acquisition and one to four validation acquisitions. A run binds ID, official source label, confined original path and SHA-256. The calibration projection has the exact columns `time_s,boundary,<sensor order>`. Validation supplies separate two-column driver and sensor-response views. `source_columns` maps these logical columns to their exact original header names. The request binds all view hashes; originals/columns are authenticated against their projections. Driver-only arrays enter forecasting before the phase change. The evaluator opens held-back originals and response views after the prediction freeze, authenticates driver projections against the declared physical boundary channel, then compares predictions. A bad projection fails the action even if the caller supplies a fresh hash for it. Lab metadata trust anchors and identity of the physical acquisitions are external.
- Exact semidiscrete time evolution with linear boundary interpolation is checked against independent implicit BDF, grid refinement, and the analytical steady profile. Calibration and predictions are separately recorded. Forecast bytes are written and hashed before accessing evaluation responses. The comparison records freeze and response-open timestamps.
- An existing ledger journal bridges published output and ledger commit. Committed outputs and both planning records are verified on resume. An attempt interrupted before atomic output publication can retry from the pinned inputs. The existing persistent episode handles the iteration/budget stop. The follow-up planner uses signs and model comparisons from the authenticated result to select the next unresolved issue. One invocation stops after comparison and replanning; recommendations for new experiments carry no authorization.
- The EvidencePacket has simulation/derived authority only. The raw inputs are existing observations; the action creates no empirical measurements, no independence certification, and no authenticated hypothesis promotion.

Tomanek–Stutts raw data are external and are not bundled. The opt-in historical test uses `MDA_ROD_HISTORICAL_ARTIFACTS` pointing to the local ARP archive. Synthetic safety tests run without it.
