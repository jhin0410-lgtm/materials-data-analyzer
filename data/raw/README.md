# Raw Data Folder Notice

The CSV files currently stored in `data/raw/` are demo/synthetic files for exercising the project workflow. They are not real experimental raw data, factory exports, customer records, or validated production data.

Only add real raw data to this folder when the dataset is public, properly anonymized, and appropriate for a public GitHub repository.

Do not commit sensitive experiment data, unpublished research data, proprietary process data, personal data, institution-owned confidential data, or customer/company data.

When real data is used for a portfolio writeup, document the dataset, source, commands, outputs, engineering interpretation, and limitations under `docs/case_studies/`.
